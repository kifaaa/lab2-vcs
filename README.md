# Проект ЛР №1 (версия из main)

Система с сетевыми структурами классов.

## Автор

Щипанский Марк Иванович, группа ИСТ-41

## Описание

Проект демонстрирует слабую связность через интерфейсы.
Вариант 1 — система логирования событий приложения.
Основной модуль `Application` зависит от абстракции `ILogger`,
а конкретные реализации (`FileLogger`, `DatabaseLogger`, `RemoteLogger`, `ConsoleLogger`)
внедряются через конструктор.
